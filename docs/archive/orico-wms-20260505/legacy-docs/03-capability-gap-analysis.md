# WMS QuickStart 能力分析 vs 行业标杆

> 对标 Extensiv 3PL / Logiwa IO / ShipHero / PackemWMS，逐功能模块评估当前版本成熟度

---

## 总体评分

| 模块 | WMS QuickStart | Extensiv | Logiwa | ShipHero | 评分说明 |
|------|:-:|:-:|:-:|:-:|------|
| **收货 (Receiving)** | 🟡 70% | 🟢 95% | 🟢 90% | 🟢 90% | 核心流程有，缺ASN自动匹配、交叉转运 |
| **上架 (Putaway)** | 🟡 65% | 🟢 90% | 🟢 85% | 🟡 75% | 有推荐库位，缺规则引擎、自动分区策略 |
| **库存管理** | 🟡 60% | 🟢 95% | 🟢 95% | 🟢 90% | 基础CRUD有，缺库存快照、库龄分析、安全库存 |
| **拣货 (Picking)** | 🟡 65% | 🟢 95% | 🟢 95% | 🟢 95% | 单单拣有，缺波次规则引擎、批量拣货、语音拣货 |
| **打包 (Packing)** | 🔴 40% | 🟢 90% | 🟢 90% | 🟢 95% | 只有验证，缺箱规推荐、重量校验、装箱清单 |
| **发货 (Shipping)** | 🔴 35% | 🟢 95% | 🟢 95% | 🟢 95% | 只记录运单号，**无运单打印、费率比价、承运商API** |
| **退货 (Returns)** | 🔴 0% | 🟢 85% | 🟢 85% | 🟢 90% | **完全没有** |
| **计费 (Billing)** | 🟡 70% | 🟢 90% | 🟡 60% | 🟡 65% | 核心计费引擎有，缺增值服务费、批量生成、对账 |
| **客户门户** | 🟡 55% | 🟢 90% | 🟢 85% | 🟢 90% | 只读查询有，缺客户自助下单、退货申请、文件下载 |
| **报表/分析** | 🔴 5% | 🟢 90% | 🟢 95% | 🟢 85% | **几乎没有**，只有API查询 |
| **集成** | 🟡 50% | 🟢 95% | 🟢 95% | 🟢 90% | Shopify Webhook有，缺Amazon完整对接、承运商API |
| **移动端** | 🟡 55% | 🟢 85% | 🟢 85% | 🟢 95% | PWA扫码有，缺完整的移动操作流程 |
| **用户管理** | 🔴 30% | 🟢 90% | 🟢 85% | 🟢 85% | 只有JWT登录，缺用户CRUD、密码重置、权限编辑 |
| **AGV/自动化** | 🟢 80% | 🔴 10% | 🟡 30% | 🔴 5% | **核心优势**，领先所有竞品 |

## 逐模块详细分析

### 1. 收货 (Receiving) — 当前 70%

#### ✅ 已有
- 创建入库单（ASN/PO）
- 逐行扫码验收（数量+损坏记录）
- 差异自动计算（over/short/exact）
- 收货完成自动生成上架任务
- 库存自动入账到暂存位

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| ASN预约到货时间 + 月台分配 | Extensiv | 中 | 2天 |
| 收货照片上传（货损凭证） | ShipHero | 高 | 1天 |
| 批量收货（扫一个托盘码收整托） | Extensiv/Logiwa | 高 | 3天 |
| 交叉转运（Cross-Dock：收货直接出库） | Extensiv | 低 | 5天 |
| 打印收货标签（托盘标/LPN标签） | PackemWMS | 高 | 2天 |
| 供应商绩效追踪（准时率/准确率） | Logiwa | 低 | 3天 |

### 2. 上架 (Putaway) — 当前 65%

#### ✅ 已有
- 系统推荐库位（同SKU合并 + 空位优先）
- 扫码确认上架
- 上架完成自动标记入库单完成
- AGV坐标信息

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| 规则引擎（按商品属性→指定区域） | Extensiv | 高 | 3天 |
| ABC分区自动分配（快销→近出货口） | Logiwa | 中 | 2天 |
| 合托/拆托操作 | ShipHero | 中 | 2天 |
| 库位容量检查（重量/体积超限预警） | Extensiv | 中 | 1天 |

### 3. 库存管理 — 当前 60%

#### ✅ 已有
- 按库位/SKU/客户查询库存
- 移库操作
- 库存调整（带审计日志）
- 盘点（Cycle Count）
- 批次/效期/LPN字段
- 不可变事务日志

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| 库存快照（每日定时快照，计费/报表用） | Extensiv | **最高** | 2天 |
| 安全库存 + 补货预警 | Logiwa/ShipHero | 高 | 2天 |
| 库龄分析（滞留报告） | Extensiv | 中 | 1天 |
| 库存冻结/解冻（质量问题暂扣） | Logiwa | 中 | 1天 |
| 序列号追踪（Serial Number） | ShipHero | 中 | 3天 |
| 组合商品/套装（Kit/Bundle） | ShipHero/Extensiv | 高 | 5天 |
| 库存导入/导出（CSV） | 所有竞品 | **最高** | 1天 |

### 4. 拣货 (Picking) — 当前 65%

#### ✅ 已有
- FIFO/FEFO库存分配
- 单单拣货（Single Order Pick）
- 拣货任务生成（按路径排序）
- 扫码确认拣货
- 订单状态自动推进

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| 波次管理（按承运商/截单时间分波） | Extensiv/Logiwa | **最高** | 5天 |
| 批量拣货（Batch Pick：多单合拣） | ShipHero | **最高** | 5天 |
| 区域拣货（Zone Pick） | Extensiv | 中 | 3天 |
| 拣货路径优化（S型/U型） | ShipHero（AI） | 中 | 3天 |
| 短拣处理（Short Pick → 自动调整订单） | Logiwa | 高 | 2天 |
| 语音拣货接口 | Extensiv | 低 | 5天 |

### 5. 打包 (Packing) — 当前 40%

#### ✅ 已有
- 扫码复核（验证商品和数量）

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| 箱规推荐（根据商品尺寸推荐纸箱） | ShipHero | 中 | 3天 |
| 重量校验（秤对接，防漏装） | ShipHero | 中 | 2天 |
| 装箱清单打印（Packing Slip） | 所有竞品 | **最高** | 1天 |
| 发票/Gift Message 打印 | ShipHero | 中 | 1天 |
| 多箱拆分（一个订单分多个包裹） | Extensiv | 高 | 3天 |

### 6. 发货 (Shipping) — 当前 35% ⚠️ 重大缺口

#### ✅ 已有
- 记录承运商 + 运单号
- 发货确认（状态更新）
- 运单号回传Shopify

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| **UPS/FedEx/USPS API对接** | 所有竞品 | **最高** | 5天/承运商 |
| **运单标签打印** | 所有竞品 | **最高** | 3天 |
| 费率比价（Rate Shopping） | ShipHero/Logiwa | 高 | 5天 |
| 批量打印运单 | ShipHero | 高 | 2天 |
| 国际发货（海关申报单） | Extensiv | 低 | 5天 |
| 运费计入客户账单 | Extensiv | 高 | 2天 |

### 7. 退货 (Returns) — 当前 0% 🔴 完全空白

#### ❌ 缺失（全部）
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| RMA创建（退货授权） | 所有竞品 | **最高** | 3天 |
| 退货收货（扫码验收退回商品） | 所有竞品 | **最高** | 2天 |
| 退货处置（重新上架/报废/退回供应商） | ShipHero | **最高** | 2天 |
| 退货原因分类 + 报表 | Logiwa | 高 | 1天 |
| 客户门户退货申请 | ShipHero | 中 | 2天 |
| 退货运单生成 | ShipHero | 中 | 3天 |

### 8. 报表/分析 — 当前 5% 🔴 几乎空白

#### ✅ 已有
- API查询原始数据
- 货主门户的统计数字（SKU数/单位数/待处理订单）

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| **仪表板（实时KPI：订单准时率/拣货准确率/吞吐量）** | 所有竞品 | **最高** | 5天 |
| 库存周转率报表 | Extensiv | 高 | 2天 |
| 客户维度报表（按客户的收发货统计） | Extensiv | 高 | 2天 |
| 员工绩效报表（拣货速度/错误率） | Logiwa | 中 | 3天 |
| 库龄/滞留报表 | Extensiv | 中 | 1天 |
| 报表导出（CSV/PDF） | 所有竞品 | **最高** | 2天 |
| 定时报表邮件推送 | Logiwa | 中 | 2天 |

### 9. 用户管理 — 当前 30%

#### ✅ 已有
- JWT登录
- 四级角色（platform_admin / tenant_admin / operator / client_viewer）
- RLS多租户隔离

#### ❌ 缺失
| 功能 | 竞品参考 | 优先级 | 开发量 |
|------|---------|:---:|:---:|
| 用户CRUD（创建/编辑/停用用户） | 所有竞品 | **最高** | 2天 |
| 密码重置/修改 | 所有竞品 | **最高** | 1天 |
| 权限细粒度配置（自定义角色） | Extensiv | 中 | 3天 |
| 操作审计日志查看 | Extensiv | 中 | 1天 |
| 多因素认证（MFA） | Logiwa | 低 | 2天 |

## 关键差距排序（按商业影响）

### 🔴 Tier 1：上线前必须补齐（客户会因此拒绝购买）

| # | 功能 | 模块 | 开发量 | 理由 |
|:-:|------|------|:---:|------|
| 1 | **运单标签打印 + 承运商API** | 发货 | 8天 | 不能打运单 = 不是一个完整的WMS |
| 2 | **退货流程（RMA + 收货 + 处置）** | 退货 | 7天 | 电商3PL退货率10-30%，没有退货 = 无法服务 |
| 3 | **波次拣货 + 批量拣货** | 拣货 | 10天 | 100+单/天的仓库必须有，否则效率太低 |
| 4 | **报表仪表板 + 导出** | 报表 | 7天 | 客户演示时第一眼看的就是Dashboard |
| 5 | **用户管理CRUD + 密码重置** | 用户 | 3天 | 没有这个 = 每次加人要找技术支持 |
| 6 | **库存CSV导入/导出** | 库存 | 1天 | 客户上线第一天要导入现有库存数据 |
| 7 | **装箱清单打印** | 打包 | 1天 | 每个包裹里都要放 |

**Tier 1 合计: 约 37 个开发日**

## 竞争优势（我们领先的地方）

| 优势 | 说明 | 竞品状态 |
|------|------|---------|
| **AGV-Ready 架构** | 库位坐标、任务队列API、车队WebSocket、就绪度校验 | 无竞品在中小3PL市场有此能力 |
| **一次性定价** | $5,300 vs $599-1,995/月的订阅 | 3年TCO优势 2-6倍 |
| **开放API** | 50+个RESTful端点 + 自动OpenAPI文档 | 多数竞品API有限或收费 |
| **手机扫码PWA** | 无需安装App，任何浏览器可用 | ShipHero有App，其他竞品需要RF枪 |
| **本地服务** | DFW现场部署 | 多数竞品只有远程支持 |

## 建议行动计划

### Sprint 1（2周）— 最小可售版本
重点：**运单打印 + 退货 + 用户管理 + CSV导入**
- Day 1-5: UPS/FedEx API对接 + 运单标签打印
- Day 6-7: 退货RMA + 退货收货 + 处置
- Day 8-9: 用户CRUD + 密码重置
- Day 10: 库存CSV导入/导出 + 装箱清单打印

### Sprint 2（2周）— 演示级版本
重点：**波次拣货 + 报表 + 批量操作**
- Day 1-5: 波次管理 + 批量拣货
- Day 6-8: KPI仪表板（准时率/准确率/吞吐量）
- Day 9-10: 报表导出 + 库存快照

### Sprint 3（2周）— 客户留存
重点：**细节打磨 + 增值功能**
- 多箱拆分 + 安全库存 + Kit/Bundle
- 上架规则引擎 + 收货照片
- 员工绩效报表
